Ascendant is an Effect-first TypeScript library for sidereal astrology.
Start by calculating D1 and D9 for a UTC moment and location. The result
contains shared **Placements** and the **Charts**: a cusp-aware D1 that
carries the KP evidence, then whole-sign divisional charts. Reuse the
placements with the other calculation modules.

<Callout
  type="warn"
  title="Python SDK is not recommended"
  className="leading-7 [&_p]:leading-7 [&_strong]:leading-7 [&>svg]:mt-1"
>
  The Python SDK ([`astro-ascendant`](https://pypi.org/project/astro-ascendant/)
  on PyPI) shares its name with the TypeScript SDK but is **not at feature
  parity** and is **not actively developed**. Use the TypeScript SDK instead. If
  you need it maintained, [fork it on
  GitHub](https://github.com/astro-ascendant/ascendant).
</Callout>

## Install

```bash
bun add astro-ascendant effect
```

<Steps>
<Step>

### Import the packages

This example uses Bun, KrishnamurtiVP291 ayanamsa, and Placidus houses
(`AstroParams.DefaultAstroParams`).

```ts
import { BunRuntime, BunServices } from "@effect/platform-bun";
import { AstroParams, Chart, Swisseph } from "astro-ascendant";
import { Console, DateTime, Effect, Layer } from "effect";
```

</Step>
<Step>

### Create the runtime layer

```ts
const runtimeLayer = Layer.mergeAll(
  BunServices.layer,
  Swisseph.SwissephLayer,
  AstroParams.DefaultAstroParams,
);
```

`runtimeLayer` provides the Bun services, Swiss Ephemeris implementation, and
default astrological parameters at the root of the program.

</Step>
<Step>

### Create the chart input

```ts
const input = Chart.ChartParams.make({
  moment: Chart.Moment.make({
    date: DateTime.makeUnsafe("2000-01-01T12:00:00.000Z"),
  }),
  latitude: 12.9716,
  longitude: 77.5946,
  sex: "Male",
});
```

`ChartParams` combines a UTC `Moment` with latitude, longitude, and optional
birth sex.

</Step>
<Step>

### Generate D1 and D9

`Chart.generate` always returns D1 first, as a `D1Chart`. Passing `[9]` adds
the D9 divisional chart, as a `DivisionalChart`.

```ts
const examples = Chart.generate(input, [9]).pipe(Effect.provide(runtimeLayer));
```

</Step>
<Step>

### Print the results

Use `Console.table` to inspect the shared placements and generated charts:

```ts
const examplesWithOutput = examples.pipe(
  Effect.tap((calculation) =>
    Effect.gen(function* () {
      yield* Console.log("Placements");
      yield* Console.table([
        {
          Point: calculation.placements.lagna.name,
          Longitude: calculation.placements.lagna.longitude,
          Retrograde: "—",
        },
        ...calculation.placements.planets.map((planet) => ({
          Point: planet.name,
          Longitude: planet.longitude,
          Retrograde: planet.is_retrograde,
        })),
      ]);
      yield* Console.log("Charts");
      yield* Console.table(
        calculation.charts.map((chart) => ({
          Division: `D${chart.division}`,
          HouseSystem: calculation.astroParams.houseSystem,
          Ayanamsa: calculation.astroParams.ayanamsa,
        })),
      );
    }),
  ),
);
```

</Step>
<Step>

### Run the program

```ts
BunRuntime.runMain(examplesWithOutput);
```

</Step>
</Steps>

`calculation.charts` is D1 followed by the requested divisions in numeric
order, so `calculation.charts[0]` is always the D1. Its houses begin at the
selected house system's cusps, and only D1 carries the chart angles, the KP
star, sub and sub-sub lords, planet significations, house significators and
ruling planets. Each divisional chart's houses are whole signs counted from
its mapped Lagna. See [Chart](/docs/api-reference/chart) for the full models.

`calculation.placements` contains the shared sidereal positions. Reuse it with
the [Dasha](/docs/api-reference/dasha), [Ashtakavarga](/docs/api-reference/sav), and
[Jaimini](/docs/api-reference/jaimini) calculators.
