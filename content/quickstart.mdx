Calculate a **D1** chart, a **D9** chart, and the running **Vimshottari
dasha** for one birth. The result is a single TypeScript file that runs on Bun
or Node.js.

<Callout
  type="warn"
  title="Use the TypeScript SDK"
>
  The Python package [`astro-ascendant`](https://pypi.org/project/astro-ascendant/)
  on PyPI shares the name but is **not at feature parity** and is **not
  actively developed**. [Fork it on
  GitHub](https://github.com/astro-ascendant/ascendant) if you need it
  maintained.
</Callout>

## Install

Ascendant needs an ES module project with TypeScript, and Bun or Node.js 20 or later.

<Tabs items={["Bun", "Node"]} groupId="runtime" persist>
<Tab value="Bun">

```bash
bun add astro-ascendant effect
```

</Tab>
<Tab value="Node">

```bash
npm install astro-ascendant effect
npm install --save-dev tsx
```

Set `"type": "module"` in `package.json` to allow top-level `await`.

</Tab>
</Tabs>

<Callout
  type="info"
  title="New to Effect?"
>
  Ascendant is built on [Effect](https://effect.website). Every calculation
  returns an `Effect`, a description of work that runs only when you run it.
  Write programs with `Effect.gen` and `yield*`, and run them once at the edge
  of your app. To learn Effect, start with [effect.website](https://effect.website),
  [effect.institute](https://effect.institute), or
  [effect.kitlangton.com](https://effect.kitlangton.com).
</Callout>

## Build the program

<Steps>
<Step>

### Create a runtime

```ts
import { Chart, Dasha, Runtime } from "astro-ascendant";
import { Console, DateTime, Effect, ManagedRuntime } from "effect";

const runtime = ManagedRuntime.make(Runtime.MainLayer);

const degrees = (value: number) => Number(value.toFixed(2));
```

Build one `ManagedRuntime` and reuse it for every calculation.
`Runtime.MainLayer` supplies the Swiss Ephemeris, a cache for repeated
position lookups, and the [default settings](#settings). `degrees` rounds
longitudes for display.

</Step>
<Step>

### Describe the birth moment

```ts
const program = Effect.gen(function* () {
  const birth = DateTime.makeZonedUnsafe("2000-01-01T17:30:00", {
    timeZone: "Asia/Kolkata",
    adjustForTimeZone: true,
    disambiguation: "reject",
  });
  const located = Chart.LocatedMoment.make({
    moment: Chart.Moment.make({ date: DateTime.toUtc(birth) }),
    latitude: 12.9716,
    longitude: 77.5946,
  });
```

Ascendant works in UTC. Convert the local time and its IANA time zone to a
UTC `Moment`, then pair it with a latitude and longitude in a `LocatedMoment`.

<Callout type="warn" title="Resolve the time zone from the place">
  The UTC offset depends on both the place and the date, so look up the time
  zone for the birth place. See [From local time to a Located
  Moment](/docs/guides/located-moments).
</Callout>

</Step>
<Step>

### Generate the charts

```ts
  const { placements, charts, astroParams } = yield* Chart.generate(located, [9]);
```

`Chart.generate` calculates the **Placements** once and derives every chart
from them. D1 always comes first, and `[9]` adds the D9. `astroParams` records
the ayanamsa and house system used. Inside `Effect.gen`, `yield*` runs an
effect and returns its result.

</Step>
<Step>

### Calculate the dasha

```ts
  const timeline = yield* Dasha.calculate(located.moment, placements);
  const current = yield* Dasha.at(timeline);
```

`Dasha.calculate` builds the full Vimshottari timeline from the same
placements. `Dasha.at` returns the Mahadasha, Antardasha, Pratyantardasha, and
Sookshma active at a moment, or now when you pass none. This example prints the
first two.

</Step>
<Step>

### Print the results

```ts
  yield* Console.log(`Placements (${astroParams.ayanamsa}, ${astroParams.houseSystem})`);
  yield* Console.table([
    {
      Point: placements.lagna.name,
      Longitude: degrees(placements.lagna.longitude),
      Star: placements.lagna.star.name,
      Pada: placements.lagna.star.pada,
      Retrograde: "—",
    },
    ...placements.planets.map((planet) => ({
      Point: planet.name,
      Longitude: degrees(planet.longitude),
      Star: planet.star.name,
      Pada: planet.star.pada,
      Retrograde: planet.is_retrograde,
    })),
  ]);

  yield* Console.log("Charts");
  yield* Console.table(
    charts.map((chart) => ({
      Chart: `D${chart.division}`,
      "Lagna Sign": chart.houses[1].sign,
    })),
  );

  if (current) {
    yield* Console.log("Running dasha");
    yield* Console.table([
      {
        Mahadasha: current.mahadasha.mahadasha,
        Antardasha: current.antardasha.antardasha,
        Start: DateTime.formatIso(current.antardasha.start),
        End: DateTime.formatIso(current.antardasha.end),
      },
    ]);
  }
});

await runtime.runPromise(program);
await runtime.dispose();
```

`Console.log` and `Console.table` are Effect versions of the console methods,
so `yield*` them like any other step. `Console.table` prints one row per object,
with the keys as column headings.

Nothing runs until `runtime.runPromise`. Call `runtime.dispose()` when you are
done.

</Step>
</Steps>

## Full program

Save it as `quickstart.ts`:

```ts title="quickstart.ts"
import { Chart, Dasha, Runtime } from "astro-ascendant";
import { Console, DateTime, Effect, ManagedRuntime } from "effect";

const runtime = ManagedRuntime.make(Runtime.MainLayer);

const degrees = (value: number) => Number(value.toFixed(2));

const program = Effect.gen(function* () {
  const birth = DateTime.makeZonedUnsafe("2000-01-01T17:30:00", {
    timeZone: "Asia/Kolkata",
    adjustForTimeZone: true,
    disambiguation: "reject",
  });
  const located = Chart.LocatedMoment.make({
    moment: Chart.Moment.make({ date: DateTime.toUtc(birth) }),
    latitude: 12.9716,
    longitude: 77.5946,
  });

  const { placements, charts, astroParams } = yield* Chart.generate(located, [9]);
  const timeline = yield* Dasha.calculate(located.moment, placements);
  const current = yield* Dasha.at(timeline);

  yield* Console.log(`Placements (${astroParams.ayanamsa}, ${astroParams.houseSystem})`);
  yield* Console.table([
    {
      Point: placements.lagna.name,
      Longitude: degrees(placements.lagna.longitude),
      Star: placements.lagna.star.name,
      Pada: placements.lagna.star.pada,
      Retrograde: "—",
    },
    ...placements.planets.map((planet) => ({
      Point: planet.name,
      Longitude: degrees(planet.longitude),
      Star: planet.star.name,
      Pada: planet.star.pada,
      Retrograde: planet.is_retrograde,
    })),
  ]);

  yield* Console.log("Charts");
  yield* Console.table(
    charts.map((chart) => ({
      Chart: `D${chart.division}`,
      "Lagna Sign": chart.houses[1].sign,
    })),
  );

  if (current) {
    yield* Console.log("Running dasha");
    yield* Console.table([
      {
        Mahadasha: current.mahadasha.mahadasha,
        Antardasha: current.antardasha.antardasha,
        Start: DateTime.formatIso(current.antardasha.start),
        End: DateTime.formatIso(current.antardasha.end),
      },
    ]);
  }
});

await runtime.runPromise(program);
await runtime.dispose();
```

## Results

- `placements`: the sidereal positions of the Lagna and the nine grahas, each
  with its star and pada. Reuse it for every other calculation.
- `charts[0]`: the **D1**. Its houses start at the house system's cusps. Only
  D1 carries the chart angles and the KP star, sub, and sub-sub lords.
- `charts[1]`: the **D9**, with whole-sign houses counted from its mapped Lagna.
- `timeline`: the full Vimshottari timeline. `current` is the period active now.

See [Core concepts](/docs/concepts) for each term.

## Settings

`Runtime.MainLayer` uses the KrishnamurtiVP291 ayanamsa and Placidus houses.
Every result records the settings it used, so you can reproduce it.

For Parashari readings, build the runtime with Lahiri and whole-sign houses:

```ts
import { AstroParams, Swisseph } from "astro-ascendant";
import { Layer, ManagedRuntime } from "effect";

const runtime = ManagedRuntime.make(
  Layer.mergeAll(
    AstroParams.layer({ ayanamsa: "Lahiri", houseSystem: "WholeSign" }),
    Swisseph.SwissephCachedLayer,
  ),
);
```

See [Choose a school and settings](/docs/guides/settings) for every ayanamsa
and house system.

## Servers

Create the runtime once at startup and call `runtime.runPromise` in each
request handler, so requests share the ephemeris cache. Call
`runtime.dispose()` at shutdown.

Every calculation can fail with a typed error, such as an invalid division or
an exhausted transit search. See [Errors and typed failures](/docs/guides/errors).
