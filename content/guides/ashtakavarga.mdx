title: Ashtakavarga
description: Calculate Bhinnashtakavarga, Sarvashtakavarga, reduced tables, and Shodhya Pinda from shared placements, and read them by sign and house.
---


**Ashtakavarga** is a classical Parashari scoring system. Eight contributors,
the Sun, Moon, Mars, Mercury, Jupiter, Venus, Saturn, and the Lagna, each give
a benefic point, a **bindu**, to some of the twelve signs. The sign scores are
then summed in several ways.

Ascendant calculates the whole system from the **Placements** you already have.

## Inputs and results

`SAV.calculate` takes only the placements. It reads the signs of the seven
classical planets and the Lagna. Rahu and Ketu take no part. It needs no moment
or location.

| Result field | What it holds |
| --- | --- |
| `bhinna` | The Bhinnashtakavarga (BAV): twelve sign scores for each of the eight entities. |
| `sarva` | The Sarvashtakavarga (SAV): twelve sign scores, the sum of the seven planetary BAVs. Excludes the Lagna. |
| `reduced` | The seven planetary BAVs after Trikona, then Ekadhipatya reduction. |
| `shodhya_pinda` | Each planet's Rashi Pinda, Graha Pinda, and their sum, the Shodhya Pinda. |
| `totals` | The total of each BAV table, plus the SAV total. |
| `provenance` | The method: Parashari `bphs-bav-trikona-ekadhipatya`. |

## Calculate

```ts
import { Chart, Runtime, SAV } from "astro-ascendant";
import { DateTime, ManagedRuntime } from "effect";

const runtime = ManagedRuntime.make(Runtime.MainLayer);

const located = Chart.LocatedMoment.make({
  moment: Chart.Moment.make({ date: DateTime.makeUnsafe("2000-01-01T12:00:00Z") }),
  latitude: 12.9716,
  longitude: 77.5946,
});

const { placements, charts } = await runtime.runPromise(Chart.generate(located));
const ashtakavarga = await runtime.runPromise(SAV.calculate(placements));
```

## Read the tables

Every table is keyed by sign name. A BAV table is keyed by entity first:

```ts
ashtakavarga.bhinna.Sun.Leo; // 6
ashtakavarga.bhinna.Lagna.Cancer; // 6
ashtakavarga.sarva.Leo; // 34
```

Scores by sign for the birth above:

| Aries | 4 | 4 | 29 |
| Taurus | 5 | 3 | 22 |
| Gemini | 1 | 2 | 22 |
| Cancer | 3 | 6 | 26 |
| Leo | 6 | 3 | 34 |
| Virgo | 5 | 5 | 33 |
| Libra | 5 | 3 | 30 |
| Scorpio | 4 | 4 | 30 |
| Sagittarius | 5 | 5 | 28 |
| Capricorn | 2 | 4 | 21 |

The other six planets have their own BAV tables under `bhinna`, keyed the same
way.

### Checksums

Each BAV table totals a fixed number, and the SAV totals 337. `totals` returns
the sums to display or assert:

| Entity | Total |
| --- | --- |
| Sun | 48 |
| Moon | 49 |
| Mars | 39 |
| Mercury | 54 |
| Jupiter | 56 |
| Venus | 52 |
| Saturn | 39 |
| Lagna | 49 |
| SAV | 337 |

Every calculation checks these against the classical values. A mismatch fails
with a typed `SAVCalculationError` naming the entity, the total found, and the
total expected. You never receive a table that breaks the rules.

## Reduced tables and Shodhya Pinda

`reduced` applies two reductions to the seven planetary BAVs: Trikona, then
Ekadhipatya. Ekadhipatya takes each pair of signs ruled by one planet and
reduces it by whether the seven planets occupy them. Reduced scores are
smaller, and many signs drop to zero:

```ts
ashtakavarga.reduced.Sun;
// Leo: 2, Virgo: 3, Libra: 4, Scorpio: 1, Sagittarius: 1, Aquarius: 3,
// and 0 in every other sign
```

`shodhya_pinda` builds on the reduced tables. For each planet it holds a
**Rashi Pinda** (weighted by signs), a **Graha Pinda** (weighted by the signs
the seven planets occupy), and their sum, the **Shodhya Pinda**:

| Planet | Rashi Pinda | Graha Pinda | Shodhya Pinda |
| --- | --- | --- | --- |
| Sun | 113 | 61 | 174 |
| Moon | 100 | 43 | 143 |
| Mars | 123 | 78 | 201 |
| Mercury | 96 | 62 | 158 |
| Jupiter | 55 | 8 | 63 |
| Venus | 130 | 69 | 199 |
| Saturn | 59 | 5 | 64 |

Use these as they are. A Shodhya Pinda is a weighted total for one planet, not
a probability and not a prediction.

## Score a house

Scores belong to signs. Look up the sign of the house in D1:

```ts
const [d1] = charts;

const tenth = d1.houses[10].sign; // "Pisces"
ashtakavarga.sarva[tenth]; // 30
ashtakavarga.bhinna.Sun[tenth]; // 4
```

Score all twelve houses at once:

```ts
const houseScores = Object.entries(d1.houses).map(([house, { sign }]) => ({
  house: Number(house),
  sign,
  sav: ashtakavarga.sarva[sign],
}));
```

For the birth above, with Gemini rising, the SAV scores of houses 1 to 12 are
22, 26, 34, 33, 30, 30, 28, 21, 32, 30, 29, and 22. The third house, Leo,
scores highest at 34.

<Callout type="info" title="Houses and house systems">
  Sign scores do not depend on the house system: they were identical across all
  13 house systems for this birth. The ayanamsa can change them, because it
  moves each planet's longitude and can move it into another sign. The sign a
  house maps to does depend on the house system. In a cusp-based system such
  as Placidus, a house starts at a cusp and `houses[n].sign` is that cusp's
  sign. For Parashari work, where each house is one whole sign, use the Lahiri
  and whole-sign settings from [Choose a school and
  settings](/docs/guides/settings).
</Callout>

## Terms

| Term | Meaning |
| --- | --- |
| **Bindu** | One benefic point given to a sign by one contributor. A sign's score is its number of bindus. |
| **BAV** | The twelve sign scores for one entity. There are eight tables. |
| **SAV** | The sum of the seven planetary BAV tables. Excludes the Lagna. |
| **Reduced BAV** | The seven planetary BAVs after Trikona and Ekadhipatya reduction. |
| **Shodhya Pinda** | A planet's weighted total: its Rashi Pinda plus its Graha Pinda. |
